# Матч Поинт

Сайт для организации киберспортивных турниров на Python, SQLite, HTML, CSS и JavaScript.

## Запуск

```powershell
py app.py
```

После запуска откройте:

```text
http://localhost:8000
```

## Доступ администратора

```text
Логин: admin
Пароль: admin
```

## Тестовые игроки

Все тестовые аккаунты используют пароль:

```text
Test12345!
```

## Возможности

- регистрация и авторизация пользователей;
- создание, редактирование и удаление турниров;
- создание, редактирование, поиск и удаление команд;
- вступление в команду по паролю или ключу;
- выход из команды и расформирование команды капитаном;
- назначение ролей участникам команды;
- регистрация команды на турнир;
- дисциплины CS2, Valorant, Dota 2, LoL, Warzone, Fortnite, PUBG и Apex Legends;
- пул карт зависит от выбранной дисциплины;
- готовые правила для каждой игры;
- бан-пик карт для конкретных матчей между командами;
- турнирная сетка с результатами и подсветкой победителей;
- рейтинг команд и игроков по очкам;
- общий чат и чат турнира;
- экспериментальный glow/liquid-glass дизайн.
